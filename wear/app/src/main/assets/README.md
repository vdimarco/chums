The original five migo GIFs were supplied by the user and are preserved here as references.

The app now renders `migo-*-poses.png`: generated replacements based on each original character, created with the built-in image_gen tool. Each transparent PNG is a three-column, two-row atlas in reading order: idle, listening, thinking, talking A, talking B, apologetic/error. Talking A/B alternate every 240 ms. No whole-sprite tilt or squash is used.

Reference frames and exact generation prompts are in `chums/design/migo-v2/`. The original launcher artwork is unchanged.
